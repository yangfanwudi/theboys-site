HASTE × THE BOYS

三角色模型替换模组 A three-character model replacement mod

为 Steam 游戏《Haste》制作的非官方粉丝模组：通过创意工坊的 AethaModelSwap 框架，把《黑袍纠察队》的祖国人（Homelander）与火车头（A-Train）替换进主角外观。纯模型替换、不含可执行代码，第一版仅支持 Windows。 An unofficial fan mod for the Steam game Haste. Built on the AethaModelSwap Workshop framework, it swaps the player character with Homelander and A-Train from The Boys. Pure model replacement with no executable code of its own — Windows only in the first release.

角色阵容The roster

两个角色，两套皮肤Two characters, two skins

每个皮肤由一份 .hastemodel 资源包、一份 IK 参数 JSON 和一枚 256×256 游戏内图标组成，全部由 Unity 6000.2.13f1 从同一套预制体构建与渲染，图标与游戏内模型保持一致。 Each skin ships as a .hastemodel bundle, an IK-parameter JSON and a 256×256 in-game icon, all built and rendered from the same Unity 6000.2.13f1 prefabs, so the icons always match the in-game models.

常见问题Troubleshooting

皮肤没有出现在游戏内列表里？The skin does not appear in the in-game list?

确认 AethaModelSwap 已订阅并启用；确认三份 .hastemodel 与同名 JSON、PNG 位于同一内容目录且文件名与清单完全一致；修改本地覆盖后重启游戏。 Confirm AethaModelSwap is subscribed and enabled; confirm the three .hastemodel files sit alongside their matching JSON and PNG files with names exactly as listed; restart Haste after changing a local override.

模型浮空、下沉或滑步？The model floats, sinks or slides?

用游戏内 Aetha ModelParamsEditor 调整 verticalOffset、stanceHeight、strideLength 与 kneesOut，再把保存的 JSON 拷回模组目录。 Tune verticalOffset, stanceHeight, strideLength and kneesOut with the in-game Aetha ModelParamsEditor, then copy the saved JSON back into the mod folder.

材质变粉或模型不可见？Materials turn pink or the model is invisible?

确认资源包由 Unity 6000.2.13f1（Built-in 管线 + Standard Shader）构建——2022.3 版构建的包无法加载；再检查 JSON 的 scale 与预制体是否位于 Assets 根目录。 Make sure the bundles were built with Unity 6000.2.13f1 (Built-in pipeline + Standard shader) — bundles built with 2022.3 will not load; then check the JSON scale value and that the prefab sits directly under Assets.

技术细节Under the hood

怎么造出来的How it is built

游戏目标Game target

Steam 版《Haste》（appid 1796470），游戏使用 Unity 6000.2.13f1；资源包必须用同一版本构建，2022.3 构建的包无法加载。 Haste on Steam (appid 1796470), built with Unity 6000.2.13f1; bundles must be built with the same version — 2022.3 bundles will not load.

文件契约File contract

每个角色三个文件：小写名 + 编号的 .windows.hastemodel、同名 JSON（IK 参数）与 256×256 RGBA PNG 图标，AethaModelSwap 按同名规则注册皮肤。 Three files per character: a lowercase .windows.hastemodel bundle, a matching JSON (IK params) and a 256×256 RGBA PNG icon; AethaModelSwap registers skins by these exact names.

渲染与贴图Rendering & textures

Built-in 管线 + Standard Shader；贴图最大 2K。骨骼为 Humanoid Avatar，动画由主角 Animator 驱动。 Built-in pipeline with the Standard shader; textures up to 2K. Rigs are Humanoid Avatars driven by the player Animator.

本地测试Local testing

开发期通过 localoverride.<PublishedFileId> 把游戏指向 dist/TheBoysPack 目录加载本地版本，测试完成后再走游戏内上传面板发布。 During development, localoverride.<PublishedFileId> points the game at the local dist/TheBoysPack folder; publishing goes through the in-game upload panel after testing.
